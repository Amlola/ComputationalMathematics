# Методы численного интегрирования

## Описание работы

В данной работе рассматриваются методы численного интегрирования для приближённого вычисления определённого интеграла функции, заданной таблично.  

Рассматриваемые методы:
- метод прямоугольников (левые, правые, по серединам),
- метод трапеций,
- метод Симпсона,
- метод Гаусса (для 2, 3 и 4 узлов).

## Запуск


```bash
python integration_methods.py
```


## Результаты вычислений

Получены следующие приближённые значения интеграла:

* **Метод прямоугольников (левые):**
  `0.15600`

* **Метод прямоугольников (правые):**
  `0.20600`

* **Метод прямоугольников (по серединам):**
  `0.18100`

* **Метод трапеций:**
  `0.18100`

* **Метод Симпсона:**
  `0.19183`

* **Метод Гаусса (2 точки):**
  `0.18936`

* **Метод Гаусса (3 точки):**
  `0.21565`

* **Метод Гаусса (4 точки):**
  `0.17340`


## Анализ результатов

Метод прямоугольников по серединам дал результат, совпадающий с методом трапеций, что объясняется использованием линейной аппроксимации функции на каждом элементарном отрезке. По сути одно и то же

Метод Симпсона показал более точный результат по сравнению с методами прямоугольников и трапеций, поскольку он основан на квадратичной интерполяции функции.

В методе Гаусса при увеличении числа точек результат меняется, что связано с характером аппроксимации функции между табличными значениями и использованием интерполяции.
