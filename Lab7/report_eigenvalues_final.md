# Лабораторная работа 3-4. Пункт 2: задача на собственные значения

## Цель работы

Адаптировать уже реализованные методы из лабораторной работы к задаче поиска собственных значений и численно решить задачу XI.9.14 для потенциальной ямы

```text
U(x) = -2 sech^2(x).
```

Нужно найти уровни энергии lambda и соответствующие им собственные функции y(x), а также функции распределения rho(x)=|y(x)|^2.


## Постановка задачи

Исходное уравнение:

```text
y'' + (lambda - U(x)) y = 0,
U(x) = -2 sech^2(x),
y(-infinity) = y(+infinity) = 0.
```

Эквивалентная форма:

```text
-y'' + U(x)y = lambda y.
```

Для численного решения бесконечный интервал заменяется конечным отрезком:

```text
[-L, L],   L = 8.
```

Граничные условия на конечном отрезке:

```text
y(-L) = 0,
y(L) = 0.
```

Ищутся отрицательные значения lambda, потому что они соответствуют связанным состояниям в потенциальной яме.

## Метод 1. Стрельба по lambda

В обычной краевой задаче метод стрельбы подбирает начальный наклон. В задаче на собственные значения подбирается параметр lambda.

Амплитуда собственной функции произвольна, поэтому можно поставить задачу Коши:

```text
y(-L) = 0,
y'(-L) = 1.
```

Для выбранного lambda решение интегрируется от -L до L. Невязка метода:

```text
F(lambda) = y(L; lambda).
```

Собственное значение находится из условия:

```text
F(lambda) = 0.
```

Для метода Ньютона используется расширенная система. Вводится z = dy/dlambda. Тогда:

```text
z'' + (lambda - U(x))z = -y,
z(-L) = 0,
z'(-L) = 0.
```

Производная невязки равна:

```text
F'(lambda) = z(L; lambda).
```

Итерация Ньютона:

```text
lambda_(k+1) = lambda_k - F(lambda_k) / F'(lambda_k).
```

Перед методом Ньютона программа сканирует интервал [-2, 0] и находит скобку, где F(lambda) меняет знак. Это сделано для устойчивости.

## Метод 2. Конечно-разностная схема и прогонка

Для проверки результата построена конечно-разностная схема для оператора

```text
H = -d^2/dx^2 + U(x).
```

На внутренних узлах получается трехдиагональная матрица:

```text
A_ii = 2/h^2 + U(x_i),
A_i,i-1 = A_i,i+1 = -1/h^2.
```

Количество отрицательных собственных значений определяется методом Штурма для трехдиагональной матрицы.

Собственная функция уточняется обратной итерацией:

```text
(A - sigma I) v_(k+1) = v_k.
```

Так как матрица трехдиагональная, на каждом шаге используется уже реализованный метод прогонки thomas_algorithm.

## Численные параметры

| Параметр | Значение | Смысл |
|---|---:|---|
| L | 8 | замена бесконечного интервала на [-L, L] |
| shoot_n | 4000 | число шагов Рунге-Кутты в методе стрельбы |
| fd_n | 800 | число разбиений в конечно-разностной схеме |
| tol | 1e-10 | точность поиска |

## Результаты

Метод Штурма показал, что отрицательный уровень один. Значит, для этой ямы найдено одно связанное состояние.

| Метод | Собственное значение | Число итераций |
|---|---:|---:|
| Стрельба с расширенной системой | lambda_1 = -0.999999099713 | 4 |
| Конечно-разностная схема + прогонка + обратная итерация | lambda_1 = -1.000014656145 | 3 |

Для проверки можно подставить y(x)=sech(x). Тогда получается аналитическое значение lambda=-1. Численные результаты хорошо совпадают с этим значением.
